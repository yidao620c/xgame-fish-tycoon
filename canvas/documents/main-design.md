## 1. 玩家幻想与核心循环

**幻想**：我是神秘岛上那家小鱼店的老板。魔法鱼消失了，我要靠育种、照看、经营，把 7 条魔法鱼重新带回水缸，让岛屿恢复平衡。

```
选鱼/买卵 → 投食喂养 → 长大成年 → 配对繁殖 → 新品种 → 进销售缸定价 → 顾客自动购买
   ↑                                                                  ↓
   └────────────────── 装备升级 / 三条研究线 ←──────────────  现金 ──┘
```

- 无时间限制、无失败结算：破产风险来自现金耗尽（还能兜售最后一条鱼续命）。
- 通关条件：7 条魔法鱼**活着并同时待在缸里**（奖杯室 7 个相框全部点亮）。

## 3. 时间

- `YEAR_SECONDS = 600`（10 分钟真实 = 1 鱼年），速度档 1× / 4× / 20×。
- 鱼卵孵化 0.12 年（约 72 秒 @1×）；20 岁成年。
- 幼鱼头顶显示 `8/20` 成长条，鱼卵头顶显示孵化倒计时。
- localStorage 持久化；离线最多补算 8 小时游戏时间（分块推进，避免跳变）。

## 4. 育子系统（441 种 = 21 鱼种 × 21 鳍基因）

- **鱼种树**：21 个节点组成二叉树。11 个叶子可在商店买卵（$160–$640），10 个杂交节点只能靠配对获得。
  配两条鱼 → 子代鱼种 = 覆盖两条亲鱼的最小子树根节点（`unite(a,b)`），与参考图「Orange Snooper + Snubbed Goldbulb → Wasp Fire-Arrow」一致。
- **鳍基因环**：21 个鳍基因按 `FIN_RING` 顺序排成一环。子代鳍基因 = 50% 父 / 50% 母；12% 突变 → 相邻鳍基因（±1）。
  稀有鳍基因（Greenfin…Wasp）被刻意夹在常见鳍基因之间，一次突变就能碰到，但要把「鱼种 + 鳍基因」凑成同一对仍需规划几代。
- **命名** = `鳍基因前缀 + 鱼种名`，例如 `Greenfin Spotanus`、`Canary Fire-Arrow`。
- **杂交弱质**：亲鱼鱼种跨度 ≥2 层的子代带 `fragile` 标记，健康慢性下降；研究「鱼缸环境」2 级后解除。
- **魔法鱼** = 7 组精确的 `(鱼种, 鳍基因)` 组合。生日语提示放在奖杯室相框背面（点击相框查看谜语），已发现的组合写入图鉴。
- 性别 50/50，同缸一雌一雄、均成年、健康 ≥25 才能繁殖；怀孕期 0.6 鱼年。

魔法鱼（组合目标，玩家需自行探索）：

| 名字 | 效果 |
| --- | --- |
| Greenfin Spotanus | 同缸怀孕鱼每窝 +1 |
| Spekled Leaffish | 同缸鱼饥饿速度 −30% |
| Crimson Comet | 同缸病鱼有概率自愈 |
| Canary Fire-Arrow | 售价极高（最高约 $475） |
| Oriental Goldbulb | 同缸鱼成长速度 +25% |
| Orange Snooper | 同缸鱼持续回血 |
| Wasp Grouper | 同缸繁殖子代基因突变率大增 |

## 5. 经营系统

| 系统 | 规则 |
| --- | --- |
| 现金 | 初始 $500；卖鱼为主要收入 |
| 水缸 | 开局拥有 1 号缸（容量 10）与销售缸（容量 6）；买「二号缸」$1200 扩到两个饲养缸 |
| 初始鱼 | 2 条成年 Spotanus（Pink / Copper 鳍，一雌一雄）+ 2 枚卵（Goldbulb / Fire-Arrow）|
| 饥饿 | 每鱼 `fed` 0–100，每年−9×饥饿系数；缸内食物池被吃空后开始下降 |
| 投喂 | 普通/浓缩/优质鱼粮分别提供 130/200/175 食物单位；水中食物上限 200 |
| 投喂过量 | `food > 90` 持续累积污染；鱼吃饱后剩下的食物白浪费 |
| 污染 | 0–100；死鱼每鱼年 +10；过滤器/蜗牛/水草/除藻剂加速净化 |
| 疾病 | 真菌病（绿褐絮状）/ 白点病（白点），需对症下药；不治会缓慢致死 |
| 死亡 | 健康归零 → 尸体漂浮，需 🗑 清理，否则持续污染 |
| 顾客 | 广告研究 + 店招 + 陈设提升到店率与购买意愿；定价高于顾客心理价则不买 |
| 兜售 | 手动立即卖出，只拿到定价的 65% |
| 销售缸 | 由店员自动投喂（从普通鱼粮库存扣），避免玩家在其它缸时展鱼饿死 |

## 6. 三条研究线（各 3 级）

| 研究 | 每级 | 费用 / 耗时 |
| --- | --- | --- |
| 鱼缸环境 | 容量 +3；2 级起杂交弱质不再慢性死亡 | $600/1200/2400，1.5/3/5 鱼年 |
| 营养学 | 鱼粮更耐饿 + 抗病力 | $400/900/1800，1/2/4 鱼年 |
| 广告营销 | 到店顾客更多、购买意愿更高 | $500/1000/2000，1/2/3.5 鱼年 |

## 7. 五个界面

1. **水缸（Tank One / Two / Sale Tank）**：canvas 绘制的水族箱（背景图 + 程序化鱼 + 气泡 + 食物颗粒），底部 HUD（Menu / Supplies / Species / Sell Fish，鱼信息卡，Health/Fed 条，现金，垃圾桶）。
2. **鱼店（Fish Store）**：等距商店场景。**待售缸改为生成立绘**（玻璃缸 + 矮木架，白底泛洪抠图、运行时合成，避免柜子过高），缸内鱼按玻璃矩形裁切绘制，价格牌钉在木柜正面。店主站在墙与柜台之间，用背景像素重绘柜台实现遮挡。顾客为侧面行走立绘，开门时店内已有 4 位不同类型顾客（含墙边看缸者），新顾客从右侧门口进入、离店也从门口走。**寻路：36×22 网格 + BFS**，销售缸与左侧柜台所占网格均为障碍（按背景图裁切换算），顾客不会踩到柜台上，目标点从「待售缸前 / 墙边展示缸 / 柜台旁」三个可走区域中选取，另加 1.5 秒无位移自动重规划兜底，顾客遇人时按 id 固定顺序上下错身（不再左右互推），行走无左右摇摆、朝向按位移方向锁定；进出店统一走右侧门口；驻足 1–3 秒。远近顾客按脚部 y 与缸体基线排序绘制。
3. **补给商店（Fish Supplies）**：24 件商品网格 + 三层木架研究台 + 物品说明面板。
4. **物种图鉴（Species Chart）**：已发现品种卡（扇形）与配种关系线；未发现显示 `?`；内置定价键盘。
5. **奖杯室（Trophy Room）**：7 个金框相框 + 统计报表。

## 8. 视觉方向

- 2004 年「实体感」写实水族箱质感：照片级背景（砾石/水草/沉木/蓝水光）+ 玻璃反光。
- 色板：深海水蓝 `#0b2b45`、水体青 `#1f7fa8`、暖木棕 `#7a4a24`、黄铜 `#d9b45a`、珊瑚红 `#d8553f`、水草绿 `#3f9f57`。
- 字体：标题用窄体衬线/圆体（`Georgia`/`Trebuchet MS` 回退），数字与系统面板用等宽感 sans。
- 所有按钮/相框/面板都用 CSS 木纹/黄铜渐变做成同一种「小屋家具」材质语言。
- 动态：鱼摆尾、气泡上升、水草摇摆、玻璃高光、选中鱼描边、投食颗粒下沉、金币飘字。

### 水缸叠加顺序

1. 封面裁剪铺位图背景 → 2. 水体染色 + 高斯模糊光柱 + 暗角 → 3. 已装装备/陈设 → 4. 食物颗粒 → 5. 鱼群（先画接触阴影）→ 6. 气泡 / 涟漪 → 7. 玻璃反光与水面线。

> 图片未加载或加载失败时，`TankView` / `StoreView` 会回退到早期的程序化场景（水体、砾石、水草、岩石/沉木），不会出现空白画面。
## 10. 技术

- Vite + TypeScript（无框架），DOM 承载面板，Canvas 2D 承载水缸与鱼店顾客。
- `src/core/` 状态与模拟（纯数据），`src/render/` 绘制，`src/ui/` 面板，`src/style.css` 主题变量。
- `globalThis.__OHMYGAME_PLAYTEST__ = { snapshot, reset, setSeed, step }` 仅用于自动化验证，正常玩法不依赖。
