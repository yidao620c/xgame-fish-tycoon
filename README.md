# 养鱼大亨 · Fish Tycoon 2D

一款致敬 2004 年经典模拟经营游戏《Fish Tycoon》的**网页复刻版**。从两条创始鱼起家，育种、繁殖、经营鱼店，目标是育出 7 条会改变玩法的魔法鱼。

纯前端实现，TypeScript + Canvas 2D，零后端、零运行时依赖，打开即玩。

---

## 一、快速开始

```bash
cd fish-tycoon-2d
npm install       # 安装开发依赖（仅 Vite / TypeScript / Playwright）
npm run dev       # 启动开发服务器 → http://127.0.0.1:5199
```

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | 开发服务器（Vite，端口 5199） |
| `npm run build` | 类型检查 + 生产构建，产物在 `dist/` |
| `npm run preview` | 本地预览构建产物 |
| `npx playwright test` | 跑自动化玩法闭环测试（3 条用例） |

## 二、玩法说明

### 核心循环

```
选鱼 → 投卵/购鱼 → 喂养 → 成年 → 配对繁殖 → 出售缸售卖 → 赚现金
                              ↑                                ↓
                          研究与装备  ←──────────────────────  ┘
```

### 时间与成长

- **10 分钟真实时间 = 1 岁**（`YEAR_SECONDS = 600`），游戏内可用 `1× / 4× / 20×` 三档加速
- **20 岁成年**，成年后才有资格配对与出售
- **鱼卵孵化约 72 秒**（0.12 鱼年）
- 缸内幼鱼头顶实时显示 `8/20` 成长进度条；鱼卵头顶显示孵化倒计时

### 经营要素

| 要素 | 说明 |
| --- | --- |
| **缸位** | 初始 1 个，购买「二号缸」后扩到 2 个 + 1 个销售缸 |
| **饲料** | 饥饿会持续掉健康并提高患病率；投喂过量（≥100%）会污染水缸 |
| **污染** | 死鱼 + 过量投喂会累积，恶化患病率；蜗牛 / 过滤器 / 除藻剂可治理 |
| **疾病** | 真菌病（绿褐絮状）与白点病（白斑），需对症用药 |
| **配对** | 同缸内一雌一雄、健康 ≥25、均已成年才能繁殖 |
| **死亡** | 健康归零即死亡；死鱼每鱼年 +10 污染，需用🗑 清理 |

### 装备与研究

商店出售 **24 种道具**，分三类：

- **一次性装备**（各带实际数值效果）：恒温器（患病率 −30%）、增氧泵（−20%）、加热棒（−10%）、过滤器（清污 ×1.8）、繁殖篮（产仔 +1）、自动投食器、鱼缸灯/店招招牌（购买意愿加成）、清洁蜗牛、特殊水草……
- **消耗品**：鱼粮 3 种、鱼药 2 种、维生素、优质鱼粮、水质测试剂
- **陈设品**：珊瑚 / 宝塔 / 沉船（提升顾客购买意愿）

**三条研究线**（各 3 级，时间与费用递增）：

| 研究 | 每级效果 |
| --- | --- |
| 鱼缸环境 | 缸容量 +3；2 级起杂交弱质鱼不再慢性死亡 |
| 营养学 | 鱼粮更耐饿、抗病力提升 |
| 广告营销 | 吸引更多顾客光顾 |

### 7 条魔法鱼（通关目标）

育出并让它们**活着待在缸里**才会生效：

| 魔法鱼 | 效果 |
| --- | --- |
| 生育魔法鱼 | 同缸怀孕的鱼每窝多产 1 条 |
| 果腹魔法鱼 | 同缸鱼饥饿速度 −30% |
| 治愈魔法鱼 | 同缸病鱼有机会自愈 |
| 黄金古比 | 售价极高，建议标价 $475 |
| 成长魔法鱼 | 同缸鱼成长速度 +25% |
| 健康魔法鱼 | 同缸鱼持续恢复健康 |
| 突变魔法鱼 | 同缸繁殖的子代基因可能突变 |

魔法鱼解锁进度记录在 **奖杯室**（2 / 3 / 2 排列的 7 个相框）。

### 五个界面

- **主缸**：养鱼、调饲料、看成长与孵化进度
- **鱼店（Sale Tank）**：出售缸里顾客自动购买，也可手动兜售；店内等距场景有NPC、思考气泡、陈列缸
- **补给商店**：24 件商品网格 + 三层木架研究台
- **物种图鉴**：21 鱼种 × 21 鳍基因 = 441 种组合的配种图
- **奖杯室**：魔法鱼收集进度 + 统计报表

### 关键实现

**双层渲染：素材优先 + 程序化兜底**

所有装饰与鱼类都有两条绘制路径，素材未就绪时自动降级为矢量绘制，游戏任何时候都不会开天窗：

```typescript
const useSprites = decorSpritesReady();   // 素材是否就绪
if (useSprites) { /* drawImage */ } else { /* 矢量绘制 */ }
```

**等距（2:1dimetric）场景**

鱼店采用等距俯视视角：紫灰平面地板 + 西/北两面垂直墙 + 分层渲染（按 y 坐标排序实现"近处遮挡远处"）：

```typescript
layers.sort((a, b) => a.y - b.y);   // 近大远小 + 近遮远
for (const L of layers) L.draw();
```

**离线收益**：关闭页面时游戏仍按真实时间推进，回来后鱼已长大。

**自动化测试**：`tests/bot-playtest.spec.ts` 覆盖完整经济闭环（选鱼 → 成年 → 配对 → 产仔 → 出售缸 → 售出）、主视图渲染、面板开合。
